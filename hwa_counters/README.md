# HWA Counters
The idea of this is to make a simple web app for keeping track of shards, heat, and agents in Hubworld: Aidalon. I am not sure if it should be used by individuals or if there should be one for each person.

## Design
Someone made an iOS app for this and will not be porting to android. So I thought it would be simple enough to make a web app with vanilla JS. Then potentially later using React, but not at first at least.
